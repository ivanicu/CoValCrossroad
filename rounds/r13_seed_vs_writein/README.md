# r13_seed_vs_writein

**Is the rubric's prompt-specific advantage carried by criteria written BEFORE the
responses existed, or by criteria written AFTER their author read all four?**

The dataset card states seed criteria were prepared in parallel with candidate
generation, while participants authored their own criteria after reading the four
candidates. The corpus therefore contains a natural experiment on r12's question.

- write-ins carry it, seeds do not -> the advantage is response-set knowledge
- seeds carry it too                -> r12's response-set reading is retracted
- neither carries it                -> the values-vs-response-knowledge axis is the
                                       wrong carve; see the meta-separator
