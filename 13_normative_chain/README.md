### Consolidators

Generated from the data on every run, never written from memory. A number in one of these that
disagrees with a round is the round being stale, not the consolidator.

| file | what it holds |
|---|---|
| [`DEFECTS.py`](DEFECTS.py) | every defect found in the release, ordered by the concrete wrong answer it produces, with later corrections wired in |
| [`HEADLINES.py`](HEADLINES.py) | every headline mean recomputed under both estimands, so no published number has an unstated unit |

Two library modules were built here and live in [`covalx`](../covalx): `estimand.py`, which refuses
a mean over grouped data until the caller names whether the unit is the observation or the group,
and `robust.py`, a calibrated jackknife whose verdict is three-valued because its own threshold is
a distribution.

Findings, intervals and caveats for every round live in the top-level [`README.md`](../README.md);
this file is a table of contents, not a second account of the results -- one home per fact.
