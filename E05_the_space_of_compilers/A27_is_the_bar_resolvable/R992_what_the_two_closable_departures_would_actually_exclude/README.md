## The method: price a proposed clause the way §4 prices an existing one

For an existing clause the remedy is *name an admissible object this clause EXCLUDES*. For a
**proposed** one, add a second step: **is that object already excluded by another clause?** A
proposed clause whose exclusions are all already excluded is decoration; one with unique exclusions
is load-bearing and has a nameable price.
