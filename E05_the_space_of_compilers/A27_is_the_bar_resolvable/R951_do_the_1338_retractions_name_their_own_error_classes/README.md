# R951 · do the retractions name their own error classes?

**The decision this made safe.** Whether §0.2's question — *are they all the same error* — can be
answered from the ledger's own text, or needs a human read of every entry.

**What it rests on.** 1,149 numbered entries parsed from RETRACTIONS.md. Only 8 participate in any
self-declared `same error as <entry>` link; 1,141 declare no such relation. Both controls held: the
one entry that declares an edge yields it, and a sentence naming a *concept* rather than an entry
yields none, so the pattern does not manufacture targets from a relation word.

**The alternatives.** Inventing a taxonomy by reading and grouping — rejected, because a taxonomy I
build from the entries is a control validated against my imagination.

**What it does not do.** Two entries can be the same error and say so nowhere. 8 is a lower bound on
declared structure, never a claim that only 8 are related. Entry-to-round links exist and are not
folded in: a round is not an error class.
