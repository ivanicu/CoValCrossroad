IDENTIFICATION
  (i) is exactly computable by reading each round's own source for the paths it opens. ⚠ "reads" is
  operationalised as a path literal appearing in the round's executable source, which OVERCOUNTS a
  path mentioned in a comment and UNDERCOUNTS one built by glob. Both directions are named, and the
  glob case is measured rather than assumed.

               claim unit      = HOW MUCH INDEPENDENT SUPPORT THE NUMBER 5 HAS
