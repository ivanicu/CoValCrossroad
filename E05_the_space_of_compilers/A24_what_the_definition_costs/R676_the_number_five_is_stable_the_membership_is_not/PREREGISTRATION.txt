⚠ DISCLOSURE, BECAUSE HALF OF THIS IS NOT BLIND. While running the prior-art gate I printed every
  artifact list containing an arm name and SAW four sets of size five with different members. So
  "there exist >=4 distinct five-member sets" and "they overlap in coval_core" are NOT predictions --
  they are observations already made, and no forecast is scored on them.

WHAT IS BLIND, AND IS REGISTERED
POINT A     the exhaustive census over ALL committed artifacts finds 6 distinct five-member arm sets.
INTERVAL A  [4, 12]
POINT B     mean pairwise Jaccard over those sets = 0.35
INTERVAL B  [0.15, 0.60]
DIRECTIONAL (separately failable) the observed mean Jaccard is ABOVE a random-5-subsets baseline
            drawn from the same arm pool -- i.e. the sets are related, not independently chosen.
KILL        if the census finds fewer than 3 distinct five-member sets, or if all but one are
            identical, there is no membership instability and the finding dies.

  g=0       the same comparator must return <1.0 on a pair known to differ.
  NEGATIVE  a set compared with a disjoint set must return 0.0.
  PLACEBO   a set against itself must return exactly 1.0.
  RANDOM    5-subsets drawn uniformly from the arm pool, same count, same seed -> the chance floor.
