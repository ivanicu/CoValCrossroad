## ⛔ Check #214 was wrong, and wrong in the way it exists to catch
I refused R614's proposed round on the grounds that *"`world` is an OPEN vocabulary — 220 distinct
values, ~95% singletons"*, so verdict class is not a variable. **That measurement is R595's, and it is
corpus-wide.** In the **post-431 era** the field is near-universal (R611: `has_world` 0.0455 → 0.9808)
and **68.4% of values carry a core first token.**

⭐⭐⭐ **The self-correction applied a measurement from one population to another — the exact error it
was invoked to prevent.** And it is the **second over-fire in two rounds**: R614's units objection was
also wrong about which number belonged to which unit.

⚠ **So the check reflex is producing false positives at a noticeable rate, and both came from the same
mechanism: a remembered number reused outside its scope.** *A correction is a claim and carries the
same scope obligation as the sentence it corrects — including the obligation to name the population it
was measured on.*

⭐ **The design absorbed the error anyway**, because the kill was computed *before* any distribution
was read: classifiable-cited **17 ≥ 8** and smallest expected cell **6.00 ≥ 5** both cleared, so the
round proceeded on measurement rather than on my wrong prior.
