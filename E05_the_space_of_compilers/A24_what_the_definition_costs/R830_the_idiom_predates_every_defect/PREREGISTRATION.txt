R830 · was the correct idiom learned, or was it always there?
registered 2026-08-06, BEFORE execution.

THE QUESTION R829 LEFT
  R829 found the correct determinism idiom -- `f() == f()`, the producer invoked twice -- in use in
  the corpus, while six rounds instead subtract a stored value from itself. R829's NEXT asked
  whether the two sets are disjoint, on the theory that a defect co-occurring with a missing idiom
  is a HABIT rather than an ACCIDENT.

⛔ THAT FRAMING IS WRONG AND IS CORRECTED HERE BEFORE ANYTHING RUNS. Every round in this corpus
  was written by the same process. "Habit vs accident" needs variation across AUTHORS, and there
  is one. The only real axis of variation is TIME, and the R-index is a time index because indices
  are assigned in sequence. So the answerable question is:
      DID THE CORRECT IDIOM ARRIVE AFTER THE DEFECTS (learning), OR WAS IT ALREADY IN USE BEFORE
      THEM (no learning)?

ESTIMAND
  The number of correct-idiom rounds with an index STRICTLY BELOW the earliest defective round.
  Named before the method. Zero => learning is possible. Non-zero => learning is refuted, because
  an idiom already in use cannot later be learned.

IDENTIFICATION
  Identified from the ordering alone. ⚠ AND IT IS PARTLY A DERIVATION: R-indices are assigned in
  sequence, so the ORDER is free. What is NOT forced is whether the two sets separate along it --
  all correct-idiom rounds could have fallen above the defects. So the observation could have come
  out otherwise and is a measurement, obtained cheaply. Labelled, per the arithmetic trap.

⛔ A NULL THAT WILL NOT BE USED, AND WHY -- written before running it again
  A permutation drawing 22 rounds at random from the 821 in the corpus gives p = 0.0002 for the
  correct-idiom rounds falling inside the defects' index span. THAT p IS INADMISSIBLE: 14 of the 22
  are the contiguous block R679-R708, so the draw treats one arc as fourteen independent units.
  n_eff is the number of CLUSTERS, not of rows. The p is recorded as WITHDRAWN, not reported, and
  the estimand above needs no null.

WORLDS
  W-LEARNED       0 correct-idiom rounds precede the earliest defect. The six are legacy, and a
                  note in the record would suffice as a remedy.
  W-ALWAYS-THERE  >=1 precedes it. The idiom was available and did not prevent the defect, so only
                  a MECHANICAL remedy can work, and the gate already built is the right one.

POSITIVE CONTROL
  A synthetic pair of index sets that ARE separated (every correct-idiom index above every defect
  index) must be reported SEPARATED. If it is not, the statistic cannot detect separation and the
  observation is UNVERIFIED.
NEGATIVE CONTROL / g=0
  Identical sets must report NOT SEPARATED, and a set drawn to straddle must report NOT SEPARATED.
CLUSTER REPORT
  n_eff is reported as the count of maximal runs of consecutive-in-corpus indices, beside the raw
  count. A raw count of 22 that is 6 clusters must not be quoted as 22 independent observations.

KILL -- a CONDITIONAL
  if the positive control reports SEPARATED and both negative arms report NOT SEPARATED:
      evaluate the estimand -> W-ALWAYS-THERE if >=1 else W-LEARNED
  else:
      UNVERIFIED, and no world is chosen.
