ESTIMAND
  For each pair R836 flagged as flipping, the TRUE paired MDE between the two arms:
      MDE_AC = ZEFF * sd(d_AC) / sqrt(n),   d_AC[p] = a2_A[p] - a2_C[p]
  and the verdict gap > 2 * MDE_AC. Named before the method.

IDENTIFICATION  identified: a2 per prompt is a pure function of the committed selection and the
                committed human rankings. Nothing is re-judged, so this is a RECOMPUTATION from
                committed artifacts, not a new measurement of the underlying scores.

WORLDS
  W-RESOLVED     at least one flagged pair is separable at the TRUE between-arm MDE. R835's
                 "no separable best" was then an artifact of its conservative resolution, and the
                 label-free class does contain an ordering.
  W-STILL-NULL   no flagged pair separates even at the true MDE. R835's verdict stands on its
                 merits rather than on its assumption, which is a stronger result than it had.

POSITIVE CONTROL  `oracle_k4` vs `generic` -- a gap of +0.0797, far above any plausible MDE -- must
                  come back SEPARABLE. If it does not, the recomputation is broken.
NEGATIVE CONTROL  an arm against ITSELF: d_AC must be identically zero, sd zero, and the pair must
                  never be separable. ⚠ Computed by scoring the arm TWICE through the same path,
                  not as `x - x`, so it also tests determinism.
g=0               the whole recomputation run twice must give byte-identical per-prompt vectors.
SEEDS             the same 3 annotator-draw seeds R436 used (0, 1, 2), and the per-seed spread is
                  reported beside the pooled number rather than averaged away.

KILL -- a CONDITIONAL
  if the positive control is separable AND the negative gives sd exactly 0 AND g=0 is identical:
      evaluate each flagged pair at gap > 2 * MDE_AC -> W-RESOLVED if any separates, else
      W-STILL-NULL
  else:
      UNVERIFIED, and both R835 and R836 stand as published.
