R829 · is the constant-control class wider than the rule that found it?
registered 2026-08-06, BEFORE execution.

WHY THIS ROUND AND NOT THE ONE I SAID I WOULD RUN
  R828's NEXT was "build the DIFFERENTIAL detector -- perturb a producer and require the round's
  own control to notice." P4 stopped it, twice over:
  (1) THE TECHNIQUE ALREADY EXISTS HERE. assurance/attack_every_check.py plants the defect each
      check hunts and requires it to FIRE. Its population is the ASSURANCE SUITE; mine would be
      the ROUNDS. So the gap is real but the METHOD IS NOT NEW, and it must not be presented as
      new: it is attack_every_check pointed at a different population.
  (2) ITS OWN HISTORY PRICES THE BUILD. Its first version reported 3 of 6 checks as never firing
      and ALL THREE WERE BAD PLANTS, not broken checks -- a 50% false-accusation rate, fixed only
      by making every plant self-validate and every check declare its contract. A differential
      sweep over rounds inherits that price, and running each round's main() costs orders of
      magnitude more than a syntactic pass.
  So before paying it: DOES THE TARGET POPULATION EVEN EXIST? The differential detector exists to
  catch constancy that is SEMANTIC rather than SYNTACTIC. If every constant control in this corpus
  is syntactically visible, the expensive sweep targets an empty set.

ESTIMAND
  The count of additional algebraically-constant control expressions in the corpus, under three
  forms the current `a OP a` rule provably cannot see. Named before the method.

THE THREE FORMS -- each SOUND, i.e. constant for EVERY input including NaN
  F1 ALIASING          `a = b` (Name to Name) and then `a - b` or `a / b`. Identical to `a - a`
                       in value, invisible to a rule comparing unparsed operands.
  F2 STRICT SELF-CMP   `x < x`, `x > x`. Always False, NaN included.
  F3 TYPE-BOUNDED      `len(...) >= 0`, `len(...) > -1`. len is a non-negative int, so no NaN
                       case exists and the comparison is always True.
⚠ REPORTED SEPARATELY AND NEVER FOLDED IN -- NaN-CONDITIONAL forms
  `x == x`, `x <= x`, `x >= x`, `abs(...) >= 0` are constant EXCEPT at NaN, and `x == x` is a
  LEGITIMATE NaN idiom. Flagging them as constant would be unsound in exactly the direction that
  manufactures a false accusation. Counted, labelled, and excluded from the estimand.

WORLDS
  W-BROADER    >=1 instance under F1-F3. The class is wider than the rule that found it, and a
               differential detector has a non-empty target population.
  W-SATURATED  0 instances. The current syntactic width already saturates this corpus, and the
               differential sweep's 50% artifact price is not yet justified by any known instance.

POSITIVE CONTROL
  Synthetic sources containing exactly one instance of F1, F2, F3 must each be flagged, and the
  matching form must be named. If any is missed the scan is blind for that form and that form's
  count is UNVERIFIED, not zero. Runs at g=0 too: a clean synthetic source must NOT be flagged.

NEGATIVE CONTROL
  A near-miss source where two DIFFERENT producers are subtracted (`a = f(); b = g(); a - b`)
  must NOT be flagged. This is the form that separates aliasing from a real comparison, and it is
  where a naive alias tracker manufactures its false accusations.

KILL -- a CONDITIONAL, not a threshold
  if every positive control fires AND the g=0 synthetic is clean AND the negative control is null:
      evaluate the count -> W-BROADER if >=1 else W-SATURATED
  else:
      UNVERIFIED. No count is reported, in either direction.

SCOPE          population: corebench + assurance + E01..E05, identical to the run that produced
               the 6, so the counts are comparable. instrument: AST over committed source.
               baseline: the existing `a OP a` rule's 6. regime: syntactic only.
MULTIPLICITY   3 sound forms + 4 NaN-conditional forms reported = 7 cells, all reported.
ARTIFACT       results/r829_wider_class.json with source hash.
IMPOSSIBLE     SEMANTIC constancy -- a producer that is constant for reasons no syntax reveals --
               is out of reach of every form here BY CONSTRUCTION. That is precisely what the
               differential detector would address, and this round measures whether it is worth
               building, never substitutes for it.
