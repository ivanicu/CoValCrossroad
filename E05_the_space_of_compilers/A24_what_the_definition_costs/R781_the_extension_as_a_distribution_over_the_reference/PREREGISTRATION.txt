--------------------------------------------------------------------------------
ESTIMAND (before method)
--------------------------------------------------------------------------------
E1  for each k=4 arm, `q(arm)` = the fraction of the 1,820-member blind reference class that the arm
    beats on paired per-prompt A2 -- the arm's ADMISSION PROBABILITY under a reference drawn at
    random from the class. Claim unit = an ARM; instrument unit = an (arm, reference) pair.
E2  the SHAPE of the distribution of `q` over the arm population. This is the estimand that decides
    whether an extension can be stated without naming a percentile.
E3  `q` computed with RESOLUTION: for each arm, the fraction of references it beats *resolvedly*
    (CI excludes 0 and |eff| >= that cell's MDE), which is the quantity R527's count-per-percentile
    curve does not carry.
E4  the same on release 2's blind class, whose cardinality is **5**, so at far lower resolution --
    reported as a transport check, never as a matched replication.

--------------------------------------------------------------------------------
IDENTIFICATION
--------------------------------------------------------------------------------
E1-E3 exact on release 1: the class is enumerable and every A2 is computable from
`sat_genericpool16.npz`.
⚠ LEAKAGE: `generic` = `POOL[0:4]` is ITSELF a member of the 1,820 class. Scoring it against a class
  containing itself gives it one guaranteed tie. Every arm is scored LEAVE-ONE-OUT against any class
  member identical to it, and the number of excluded self-matches is printed.
E4 IDENTIFIED BUT UNDERPOWERED BY CONSTRUCTION: release 2 ships `core_generic.json` at k=4, so no
  16-criterion pool exists there and the blind class is the 5 scored blind arms. `q` on 5 references
  takes 6 possible values; it can order arms coarsely and cannot resolve the distribution's shape.

--------------------------------------------------------------------------------
THE ARITHMETIC, DERIVED BEFORE MEASURING
--------------------------------------------------------------------------------
D1  "BEATS A RANDOM DRAW WITH PROBABILITY > 1/2" IS PERCENTILE 50, EXACTLY. It is a DERIVATION, not a
    new rule, and any round presenting median-dominance as a parameter-free fix is renaming p50.
D2  "BEATS THE CLASS MEAN" IS ALSO A PERCENTILE -- the one the class's skew puts the mean at. It is
    computed rather than chosen, which removes the free parameter but changes no level. **Also a
    DERIVATION.** Both are stated here so the round cannot later report either as a finding.
D3  ⭐ THEREFORE THE ONLY NON-DERIVED CONTENT IS THE DISTRIBUTION'S SHAPE. If `q` is bimodal at 0 and
    1, the percentile choice moves only a few borderline arms and an extension can be stated as
    {admitted} + {borderline, named}. If `q` piles up near 0.5, then clause ② cannot support any
    extension without naming its comparator, and the definition has a free parameter it must
    surrender. **This could come out either way, which is why it is the estimand.**
D4  p100 IS EXCLUDED AS A CANDIDATE RULE IN ADVANCE, on R666's finding that emptiness at p100 is
    substantially forced -- a maximum over 1,820 in-sample references is an order statistic, not a
    reference.

STRONGEST CONFOUND, written BEFORE the run: the 1,820 subsets are not independent -- they share
criteria, so `q` is a fraction over a highly correlated class and its effective n is far below 1,820.
CONTROL IN THE SAME ITERATION: report the class's effective size via the mean pairwise correlation of
reference A2 vectors, and report `q` against a null built by resampling references in a way that
preserves that correlation (block resampling by shared criterion), never as though 1,820 were
independent draws.

--------------------------------------------------------------------------------
WORLDS
--------------------------------------------------------------------------------
A · THE CHOICE IS DECISIVE. `q` concentrates near 0.5 for most arms. Then which blind set is named as
    the comparator determines admission for most of the population, clause ② states nothing about an
    arm without its comparator, and the definition must carry the reference in its text.
B · THE CHOICE IS MARGINAL. `q` is bimodal near 0 and 1 with few arms between. Then the 4 -> 8
    movement R527 measured is a handful of borderline arms, and the definition CAN state an extension
    parameter-free: the arms with q ~ 1, plus a named borderline set.
C · ORDERED BUT UNRESOLVED. `q` spreads smoothly with no mode. Then the class induces an ordering and
    no natural cut, and the honest formulation reports `q` per arm instead of an extension.

PREDICTION MATRIX
  A -> >= half the arms have q in [0.35, 0.65]
  B -> >= half the arms have q < 0.10 or q > 0.90, AND fewer than a quarter in [0.35, 0.65]
  C -> neither

--------------------------------------------------------------------------------
KILL -- CONDITIONAL, gated on the controls
--------------------------------------------------------------------------------
if OBJECT passes (the class is exactly C(16,4) = 1,820; self-matches excluded and counted; exit 2
   otherwise) and POSITIVE fires (a synthetic arm built to dominate returns q = 1, and one built to
   be dominated returns q = 0) and g=0 fires (a class member scored against the class returns q near
   its own rank, not 0 or 1) and PLACEBO fires (an arm against itself = 0.5 or exactly tied):
        >= half of arms in [0.35, 0.65]                 -> WORLD A
        >= half outside [0.10, 0.90] and < 1/4 in the
          middle band                                   -> WORLD B
        neither                                         -> WORLD C
else:
        UNVERIFIED. Never OVERTURNED, never CONFIRMED.

--------------------------------------------------------------------------------
CONTROLS
--------------------------------------------------------------------------------
OBJECT     the enumerated class has exactly 1,820 members and every member has 968-prompt coverage;
           the count of self-matches excluded is printed. Exit 2 otherwise.
POSITIVE   two synthetic arms: one whose per-prompt A2 is the class maximum plus a margin (must
           return q = 1) and one at the class minimum minus a margin (must return q = 0). BAND,
           COMPUTED: floor and ceiling are the two synthetic arms' own q, and any real arm's q is
           required to lie between them -- a band whose ends are measured, not typed.
g=0        a genuine class member scored leave-one-out must return its OWN rank in the class, which
           is a computed number and not 0 or 1. This is the control that fails if the estimator is
           accidentally comparing an arm to itself.
NEGATIVE   permute the per-prompt pairing between arm and reference, 200 draws -> the q distribution
           under no alignment. The world excluded: "any two A2 vectors give this q".
SHAM       ingredient ABSENT: a reference class built from the SAME 16 criteria but with per-prompt
           satisfactions shuffled across prompts -- prompt-blindness preserved, criterion content
           destroyed.
PLACEBO    an arm against a class consisting of itself: exactly tied.
DEPENDENCE the class's mean pairwise A2 correlation and the resulting effective size, printed BEFORE
           any q is interpreted.
UNIT       instrument unit = an (arm, reference) comparison; claim unit = an ARM. Named separately.
