R787 · `q` is a monotone COARSENING of A2 — the 1,820-member class contributes a threshold, nothing else
WRITTEN BEFORE ANY CODE FOR THIS ROUND. 2026-08-06.

--------------------------------------------------------------------------------
WHY THIS ROUND EXISTS
--------------------------------------------------------------------------------
R786's A2-CHECK measured `corr(A2, q_resolved)` at **+0.9601** sham-free and closed by asking whether
the residual of q_resolved on A2 is distinguishable from zero across the modal-k=4 population.

⛔ CHECK #389 DERIVED THE ANSWER BEFORE MEASURING IT, WHICH IS WHAT THE ARITHMETIC TRAP DEMANDS. The
per-reference statistic is a paired mean:
      mean( v_arm − REF_i )  =  mean(v_arm) − mean(REF_i)  =  A2_arm − A2_ref_i
so **an arm beats reference i if and only if its A2 exceeds that reference's A2.** Therefore
      q(arm) = the fraction of the 1,820 references whose A2 is below the arm's
             = the arm's PERCENTILE in the reference A2 distribution
which is a **deterministic, monotone, non-decreasing step function of A2 alone**. Nothing else about
the arm enters. `q_resolved` adds one term — each reference's own MDE, `ZEFF·sd(d_i)/sqrt(P)`, which
depends on the VARIANCE of the per-prompt difference — so it is the same percentile modulated by a
variance correction, and that correction is the only place independent information could live.

MEASURED IN CHECK #389 over R782's 26 modal-k=4 arms:
      Kendall tau(A2, q)          **+1.0000**, 197 concordant, **0 discordant**
      Kendall tau(A2, q_resolved) **+1.0000**, 240 concordant, **0 discordant**
      distinct values: A2 **19**, q **4**, q_resolved **6**

⇒ **`q` carries strictly LESS information than A2**, and four rounds — R781, R782, R783, R786 — have
reported it as though it were a separate quantity. This round states what it actually is and what the
reference class actually contributes.

--------------------------------------------------------------------------------
THE ARITHMETIC, DERIVED BEFORE MEASURING
--------------------------------------------------------------------------------
D1  q IS A MONOTONE FUNCTION OF A2, EXACTLY. Shown above: the paired mean equals the difference of
    means, so the sign is decided by A2 alone. **DERIVATION — it could not have come out otherwise**,
    and E1 exists to confirm the code implements the algebra rather than to discover the algebra.
D2  THEREFORE Kendall tau(A2, q) = +1 IS ALSO A DERIVATION and is NOT evidence. Reporting the tau as a
    finding would be exactly the arithmetic trap. It is printed as a CHECK ON THE CODE.
D3  q_resolved IS NOT FULLY DETERMINED BY A2. Its MDE term depends on `sd(v − REF_i)`, so two arms
    with identical A2 can differ. **This is the only place independent information can live**, and E4
    is built to isolate it. Its zero inversions over 240 real pairs is a MEASUREMENT and is reported
    as one.
D4  A COARSENING CANNOT ADD INFORMATION. 19 distinct A2 values becoming 4 q values is a strict loss;
    no analysis downstream of q can recover an ordering that q has already collapsed. **DERIVATION**,
    and it is the reason this matters rather than being a curiosity.

STRONGEST CONFOUND, written BEFORE the run: the reference class's A2 values are themselves computed
with the same judge and the same prompts as the arms', so a shared judge artifact could make both move
together and manufacture the monotonicity. CONTROL IN THE SAME ITERATION: the monotonicity is an
ALGEBRAIC identity, not a correlation, so a shared artifact cannot produce it — but E1 verifies the
identity pair by pair, and if any pair disagrees the confound becomes live and is reported.

--------------------------------------------------------------------------------
WORLDS
--------------------------------------------------------------------------------
A · q IS A COARSENING AND THE CLASS IS A THRESHOLD. E1's identity holds on every pair, tau is +1, and
    E4's synthetic shows the variance term either cannot invert or inverts only outside the range the
    arms occupy. Then "clause ② standing" is A2 with cut points, the cut points are the class's whole
    contribution, and the definition should say so.
B · q_resolved CARRIES REAL INDEPENDENT INFORMATION. E4's synthetic inverts within the arms' observed
    A2 range. Then the variance term is a live second dimension, zero inversions in 240 pairs is a
    fact about this population rather than about the statistic, and the class contributes more than
    a threshold.
C · THE IDENTITY FAILS. Some (arm, reference) pair disagrees with the algebra. Then the implementation
    is not computing what I derived, every q in this arc is UNVERIFIED, and the round's product is
    that discovery.

  B -> E1 disagreements = 0 AND E4 inverts within the observed variance range
  C -> E1 disagreements > 0

CONTROLS
--------------------------------------------------------------------------------
OBJECT     R782's artifact carries `a2` and `q_res`; the 1,820 references rebuild exactly. Exit 2.
PLACEBO    an arm against itself: paired mean exactly 0, and q of a reference against its own class
           equals its own rank (R781's g=0, reused because it is the control that catches
           self-comparison).
POSITIVE   place a synthetic arm at a chosen A2 by adding a constant to a real arm's per-prompt
           vector; its q must equal the fraction of references below that A2, computed independently.
           BAND, COMPUTED: at a constant of 0 it must reproduce the arm's own q, and at a constant
           above the class maximum it must return exactly 1.0.
NEGATIVE   ⛔ NOT BUILT as a permutation. D1: q is an algebraic function of A2, so permuting the arm
           across prompts leaves A2 and therefore q unchanged — the void control of ledger 1125/1129,
           declined for the third round running and for a reason now derived rather than remembered.
SHAM       the ingredient is THE CLASS. Removing it = scoring against a single reference. Both are
           computed, so the class's contribution over one comparator is visible rather than assumed.
VARIANCE   E4's synthetic: two arms with identical A2 and deliberately different `sd(v − REF)`,
           swept over a variance ratio, with the observed range of real arms marked on the sweep.
UNIT       instrument unit = an (arm, reference) pair; claim unit = an ARM. Unequal and stated.
