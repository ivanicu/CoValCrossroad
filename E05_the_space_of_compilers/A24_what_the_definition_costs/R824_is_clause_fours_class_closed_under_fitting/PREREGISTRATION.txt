R824 · IS ④'s CLASS CLOSED UNDER FITTING? THE TEXT IS SILENT AND THE EXTENSION MAY DEPEND ON IT

CHECK #426. R823's NEXT — "fit a response-only predictor and measure its bar against 0.455679" —
passes the gauge and arithmetic rungs (the outcome is not forced). BUT IT WALKS PAST ITS OWN
PREMISE. ④ reads, verbatim (DEFINITION.md:24):

    "scores better, under that same judge J, than EVERY RULE COMPUTABLE FROM THE RESPONSE SET ALONE"

That sentence constrains what a rule CONSUMES AT INFERENCE. It is SILENT about what the rule's
CONSTRUCTION consumed. R435's thirty are hand-built and read no labels ever. A supervised predictor
reads only responses at inference but was FIT on human labels from other prompts. Two readings:

  STRICT      a rule is a function of responses with no parameters fit on human data
              -> the class is the 30 hand-built rules; bar = 0.455679 (R823)
  PERMISSIVE  the rule at inference reads only responses; its parameters may come from other
              prompts' labels -> the class contains every supervised response-only predictor

Both are defensible English. NOBODY IN 400 ROUNDS HAS BUILT AN OBJECT THAT DISTINGUISHES THEM, and
③'s own wording ("no information from THAT PROMPT's own human labels") shows the deliverable already
uses the fit-on-other-prompts distinction elsewhere -- so the ambiguity is not hypothetical.

  E2  ④'s exclusion count over the 58 arms under each reading

DERIVED FIRST -- BEFORE ANY COMPUTE

      (the single feature is in the hypothesis class). So an IN-SAMPLE rise is FORCED and is not
      evidence. Only the HELD-OUT bar can come out otherwise, and E1 is held-out for that reason.
  D2  The permissive class CONTAINS the strict class, so permissive_bar >= strict_bar is forced in
      sample. Held out it is NOT forced -- R823 measured the held-out floor FALLING from 0.456094
      (m=6) to 0.454779 (m=30) as the class grew, so a bigger class can lower a generalising bar.
  D3  ③ is a property of an ARM; ④'s class is a BAR. A predictor entering ④'s class does not have
      to satisfy ③. Conflating them would import a constraint the text does not carry.
  D4  This round settles whether the READING CHANGES THE EXTENSION. It does not choose the reading
      on grounds of taste; if the extension is identical under both, the ambiguity is EMPIRICALLY
      EMPTY and the text needs no repair -- which is a stronger outcome than picking a side.
