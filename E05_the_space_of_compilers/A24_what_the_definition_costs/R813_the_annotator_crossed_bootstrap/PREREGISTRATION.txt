⭐ BUT THE SAME CHECK FOUND THE REAL DEPENDENCE, AND IT IS NOT OVER PROMPTS. **1,012 distinct
annotators, each judging a MEDIAN OF 19 PROMPTS (mean 18.1, max 38), and ALL 1,012 touch more than
one.** Annotators are CROSSED with prompts. Every interval this arc has quoted resamples prompts
while holding the annotator panel fixed, so annotator-level error is treated as if it were
independent across the ~19 prompts each annotator touches. Ignoring a crossed random effect makes
intervals TOO NARROW, and this arc's smallest surviving effect (R810's +0.0116 at k=12, half-width
0.0046) would not survive a design effect of 2.

IDENTIFICATION
Identified: annotator ids are on every assessment. ⚠ Resampling annotators leaves some prompts with
ZERO annotators in a draw; those prompts are dropped FROM THAT DRAW and the mean number dropped is
reported. If more than 10% of prompts are lost on average the estimand is degraded and the round
says UNVERIFIED rather than quoting a width built on a shrinking population.

DERIVED BEFORE MEASURING
D1 [DERIVATION] a bootstrap that resamples one axis cannot be WIDER than one resampling two, in
   expectation. If the crossed interval comes out NARROWER than the prompt interval, the code is
   wrong and the round says so rather than reporting a design effect below 1.
D2 [DERIVATION] an arm against ITSELF is exactly 0 in every draw, so its interval has zero width
   under every scheme. PLACEBO.
D3 breaking the crossing -- reassigning annotator ids at random -- must collapse the annotator
   bootstrap's width toward the prompt bootstrap's. NEGATIVE, and it is the world "annotators do not
   carry shared error" built explicitly rather than assumed.
D4 a planted annotator-specific offset must widen the ANNOTATOR interval and leave the PROMPT
   interval nearly unmoved. POSITIVE, with a known direction; and at offset 0 it must NOT fire.

WORLDS
A  NARROW: design effects <= 1.2 -> prompts dominate and this arc's intervals stand as quoted.
B  UNDERSTATED: design effects >= 1.5 on any headline AND at least one loses resolution -> the
   intervals must be restated, and the correction reaches the DEFINITION broadly.
C  BETWEEN: widths grow but no verdict flips -> intervals restated, conclusions kept.
