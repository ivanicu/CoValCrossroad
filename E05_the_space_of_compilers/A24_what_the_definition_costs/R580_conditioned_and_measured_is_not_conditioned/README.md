# R580 · "Conditioned" and "measured to be conditioned" are different claims

**Decision this makes safe:** what a scope marker may assert.

**WORLD B.** Artifacts that vary the extension along each G1 axis:

| axis | artifacts | status |
|---|---|---|
| `baseline` | **9** | measured |
| `population` | **6** | **measured — and R579 never named it** |
| `target` | **2** | measured |
| **`regime` (k)** | **0** | ⚠ **untested** |

## ⭐⭐⭐ Two errors, in opposite directions, in the same marker
- **R579's marker named two axes. Three have measurements.** `population` was varied across
  **6** artifacts and appeared in no caveat.
- **And the correction is not "list all four."** `regime` has **zero** measurements against this
  number. **Listing it as a condition would assert something nobody measured** — and that is the
  flattering error, because **a longer caveat reads as more careful.**

**The marker now names the three measured axes and states that `regime` is untested.** *Conditioned*
and *measured to be conditioned* are different claims, and only the second is evidence.

## Controls
- **Positive** — the target sweep (`R288`, `R558`) is found, so a zero elsewhere is a measurement.
  **PASS.**
- **Negative** — an invented axis vocabulary matches **0** artifacts. **PASS.**
- **Discriminating**: the four axes return **9 / 6 / 2 / 0** — four distinct values, not a uniform
  column. *(R575's dead-instrument signature, checked before the verdict.)*

⚠ **Not established:** that `regime` **does** condition the number. **Only that nothing has measured
it** — which is why it is marked untested rather than added to the list.
