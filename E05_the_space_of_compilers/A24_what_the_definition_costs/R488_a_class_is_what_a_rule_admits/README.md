## Produced

`assurance/arm_population_is_derived.py` — for arms, what `comparator_scope.py` is for comparators.
**143 of 464 rounds load arm artifacts: 32 derive · 1 declares · 31 type by hand.**

⛔ **Its first detector was blind to the very rounds it was built from.** It matched assignments named
`ARM|arms$`; the positive control — built from R477, R485, R486, R487 — **failed 3 of 4**, because
those rounds name the variable `ADMISSIBLE`, `adm_aware`, or build it inline. **93 of 143 landed
unclassified. An invented test case would have passed.**

**Regrounded in the object:** an arm list is a list of strings that **are** arm names, and arm names
are on disk. ⚠ That overshot — R487, which derives its population, was flagged because it also holds
`BLIND` and `CORE_FAMILY`, literal sets used as **exclusions**. **A literal used to exclude is a rule
component.** Resolved by precedence, with the cost named in the file: *a round that globs for
something else and hand-types its arms reads as DERIVED.* Sound in one direction only.

⭐ **A RATCHET, not a gate — because of R483.** The 31 are frozen so the debt cannot grow, and the
check **also fails when a frozen entry stops typing**, so the list shrinks and cannot become the
confession nobody re-reads.

**Attacked five ways before trusted:** a new typed round → caught · the ledger **deleted** → all 31
read as new debt, never a clean bill · a stale frozen entry → caught · the classifier neutered to
always say DERIVED → **its own positive control fails it** · an empty corpus → **exit 2**.
