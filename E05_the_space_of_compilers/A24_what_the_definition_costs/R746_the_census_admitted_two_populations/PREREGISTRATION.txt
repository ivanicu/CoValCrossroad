DIRECTIONAL, separately failable
D   coverage does NOT predict admission -- the share of low-coverage arms among the admitted is no
    higher than among the non-admitted. If it IS higher, low coverage is an admission ADVANTAGE and
    that is a defect in the construction, not a scope note.

--------------------------------------------------------------------------------
⛔ THE ARITHMETIC, DERIVED BEFORE MEASURING -- AND IT POINTS THE OTHER WAY
--------------------------------------------------------------------------------
R728's re-implementation computes `mde = ZEFF * std / sqrt(n)`. So at equal std, going from 968 to
200 prompts MULTIPLIES the mde by sqrt(968/200) = 2.20. A 200-prompt arm must clear a threshold
2.2x LARGER, which makes its admission HARDER, not easier.

This is a DERIVATION and it is the strongest confound stated in the round's own favour-free
direction: low coverage is not obviously a leak, and framing it as one before checking would be the
cheap-attack failure. CONTROL IN THE SAME ITERATION: measure the realised mde of each admitted arm
and report whether the low-coverage ones cleared a wider or a narrower bar than the rest.

⚠ The direction that WOULD be a defect is different and must be tested separately: if the 200
prompts are a NON-RANDOM subset -- for instance whichever ones a second judging run could afford --
then the estimate is biased even though the interval is wider. Coverage size and coverage
composition are two questions and only the first is settled by counting.

--------------------------------------------------------------------------------
CONTROLS
--------------------------------------------------------------------------------
POSITIVE   the coverage parser must return DIFFERENT values for two arms whose FILE SIZES differ by
           4.5x -- file size is an independent signal the parser never reads. BAND, COMPUTED: floor
           = a parser returning a constant (cannot separate), ceiling = the true distinct count.
           Threshold: the two arms differ AND the constant parser does not separate them, asserted.
g=0        an arm whose meta is empty must be reported UNREADABLE, never as 0 prompts. A silent
           zero would enter the low-coverage count and manufacture World B.
NEGATIVE   parse field 1 (the selection index) instead of field 0 (the prompt id). The coverage
           numbers must change drastically. World excluded: "any field of this string gives 968".
SHAM       the same operation with the INGREDIENT ABSENT, not inverted. Ingredient = being ADMITTED.
           Run identical coverage counting on the arms the census did NOT admit. If the coverage
           spread is the same there, coverage is a property of the store rather than of admission.
PLACEBO    each arm's coverage compared with itself -> exactly 0 difference, over all 92.
NOISE      no rng. The variance is the COVERAGE DEFINITION: three variants swept --
             prompts   distinct field-0 values
             cells     len(meta)
             pairs     distinct (pid, j) selections
UNIT       instrument unit = one TAG's npz file; claim unit = one ARM's evidence base. Equal here,
           because a tag maps to exactly one npz -- asserted in code rather than assumed, and any
           tag resolving to zero or two files is reported.
