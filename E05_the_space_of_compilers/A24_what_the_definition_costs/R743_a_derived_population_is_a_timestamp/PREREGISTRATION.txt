--------------------------------------------------------------------------------
WORLDS -- ontologically different, not parametric
--------------------------------------------------------------------------------
A · THE CONSTANT IS A SCOPE.
    The cited rounds enumerate their arms. "41 arms" is a property of the claims, stable under
    re-running, and R728's glob finding is LOCAL to the census round.

B · THE CONSTANT IS A TIMESTAMP.
    The cited rounds glob. "41" is the size the directory had on the day each round ran. The
    page's one population row is a fossil, and every row inheriting it is conditioned on a DATE
    rather than on a population. The existing gate arm_population_is_derived.py certifies exactly
    this pattern as the SAFE side, so the tree has been rewarding what makes the number expire.

C · MIXED, AND WORSE THAN EITHER.
    Some cited rounds glob and some enumerate. Then ONE column cannot carry both, and the defect
    is not a wrong number but a column that is unstateable as written.

PREDICTION MATRIX -- glob fraction f among cited rounds
    A -> f <= 0.25       B -> f >= 0.60       C -> 0.25 < f < 0.60

CONTROLS

POSITIVE   two rounds whose class is known independently of this instrument:
             R728 -- the round that FOUND the census glob -> must classify DERIVED
             R719 -- runs on the literal set PUBLISHED_FIVE -> must classify TYPED or DECLARED
           BAND, COMPUTED NOT CHOSEN: floor = a classifier that never sees a glob (0 DERIVED),

NEGATIVE   take a known-DERIVED source, delete every glob/iterdir/listdir call, keep everything
           else. Class must FLIP. Names the excluded world: "the classifier fires on any file".
SHAM       the SAME operation with the INGREDIENT ABSENT -- not inverted. Ingredient = being cited
           by a claim row. Run the identical classifier on the COMPLEMENT population (A24 rounds
           not cited by the claim rows). If f is the same there, "cited rounds glob" is a property
           of the tree and not of the claim rows.
PLACEBO    classify files that contain no Python (the rounds' README.md). Must return 0 of 0, and
           the report must distinguish "0 of 0" from "0 of N".
NOISE      the classifier is deterministic on source; the real variance is the DETECTOR CHOICE.
           Sweep three variants and report all three -- that is the specification curve, not a
           robustness footnote.
UNIT       instrument unit = one run.py file; claim unit = one round. Require EQUAL: assert every
           cited round resolves to exactly one run.py, and report any that do not.
