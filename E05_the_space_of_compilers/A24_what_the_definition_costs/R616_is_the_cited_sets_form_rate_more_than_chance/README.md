## ⛔ Check #215: I named the property wrong
R615 closed calling this **legibility** — *"writing a verdict in the corpus's shared vocabulary"*. The
instrument measures **first token ∈ {A,B,C,D,E,UNVERIFIED}**. **R591's own `world` is `"MIXED — 0.5404=A
truncated citation …"`** — a well-formed, informative verdict this rule calls absent.

⚠ **Instrument unit ≠ claim unit, so the property is renamed to what is measured: SIX-TOKEN FORM.**
*The renaming is not cosmetic — "the page prefers legible rounds" and "the page prefers rounds using
six specific letters" license completely different conclusions, and only the second is supported.*

## ⚠ The positive control lands exactly on the observation, and that is a real limit
Drawing a cited set only from six-token rounds gives **Δ = +0.3506** — **identical to the observed
value**, because the cited set already is 17/17 and the ceiling is 1.0. **So the positive control
proves the instrument can REACH this value; it cannot show the value could be exceeded.**

⭐ *A control that coincides with the observation demonstrates attainability, not discrimination.* The
verdict rests on the **null** (+0.2200) rather than on the positive control, and that is stated rather
than left for a reader to notice.
