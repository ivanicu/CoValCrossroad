R835 · a performance bar cannot get discriminating power from the ordering it sits in
registered 2026-08-06, BEFORE execution.

⚠ A HYPOTHESIS I CHECKED AND DISCARDED BEFORE DESIGNING ANYTHING. I expected an ASYMMETRY: ③
  forbids the core its prompt's labels while ④ lets the bar be FIT on labels. Reading both clauses
  verbatim: ③ forbids "that prompt's OWN human labels", and ④ permits fitting on OTHER prompts'.
  The core is not forbidden other prompts' labels either, so there is no asymmetry there. Discarded.

THE ARITHMETIC THAT MOTIVATES THIS ROUND -- a derivation, stated before any run
  A definition of the form [provenance restriction P] ∧ [beat an ABSOLUTE bar B] has extension
      EMPTY                    if B > ceiling(P)
      non-empty, maybe VACUOUS if B <= ceiling(P)
  and NOTHING in the definition ties B to ceiling(P). They are on independent axes, so the
  extension is decided by where B happens to sit -- which is exactly what R826 measured: the bar
  SATURATES ON the released core and the verdict flips across the plateau.
  ⛔ AND THE OBVIOUS FIX IS ALSO BROKEN. ④' = "beats every rule IN THE SAME PROVENANCE CLASS" is
  never empty, because the class's own maximum satisfies it BY CONSTRUCTION. That is a CHECK THAT
  CANNOT FAIL, §4's first row. So BOTH forms fail, for opposite reasons, and neither failure is a
  measurement -- both are forced.

⭐ WHAT THAT LEAVES, AND IT IS THE ONLY PART THAT CAN COME OUT OTHERWISE
  A bar has discriminating power only when anchored to something OUTSIDE the ordering. The cheapest
  external anchor this site already computes is the design's own resolution:
      ④'' the core beats the best OTHER rule in its provenance class BY MORE THAN THE MDE.
  Whether ④'' is satisfiable here is a FACT ABOUT THE WORLD, not about the ordering.

ESTIMAND
  Among arms ③ admits (by partition or by construction record), is any arm separably better than
  the next -- gap > the design's own MDE? Named before the method. Reported per candidate.

IDENTIFICATION  identified from R436's committed per-arm `a2` and `mde`. ⚠ `mde` there is the arm's
                own paired bootstrap MDE against the BAR, not against another arm, so it is an
                APPROXIMATION to the between-arm resolution and the round says so rather than
                pretending otherwise. Where the gap is within 2x of the MDE the cell is UNRESOLVED.

WORLDS
  W-NO-SEPARABLE-BEST  no ③-admissible arm beats the next by more than the MDE. Then ④'' is EMPTY
                       too, and the finding is that this site cannot support ANY performance clause
                       with discriminating power inside the label-free class.
  W-SEPARABLE-BEST     some arm does. Then ④'' is a well-formed clause here and names that arm.

POSITIVE CONTROL  the FULL ordering, including label-readers: `oracle_k4` (0.6353) against the best
                  ③-admissible arm must be separable. If even that gap is inside the MDE the
                  instrument cannot resolve anything and the round is UNVERIFIED.
NEGATIVE CONTROL  an arm against ITSELF must give gap 0 and never separable. ⚠ Computed by looking
                  the arm up TWICE from the artifact rather than as `x - x`.
KILL -- a CONDITIONAL
  if the positive control is separable AND the negative is not:
      evaluate -> W-SEPARABLE-BEST if any adjacent gap in the ③-admissible ordering exceeds its
      MDE, else W-NO-SEPARABLE-BEST
  else:
      UNVERIFIED, and no world is chosen.

MULTIPLICITY   every adjacent pair in the ③-admissible ordering is reported, separable or not.
SCOPE          population: R436's 93 arms. instrument: R436's committed a2 and mde. baseline: the
               arm's own MDE. regime: A2, this judge, this release.
ARTIFACT       results/r835_external_anchor.json with source hash.
IMPOSSIBLE     a TRUE between-arm MDE needs the paired difference vector for each arm PAIR, which
               R436 did not persist -- it persisted each arm against the bar. Recomputing it needs
               the per-prompt score vectors, so this round reports an APPROXIMATION and names it.
