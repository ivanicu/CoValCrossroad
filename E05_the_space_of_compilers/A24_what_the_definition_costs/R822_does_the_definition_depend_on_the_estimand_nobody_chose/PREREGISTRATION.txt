DERIVED FIRST -- ALL FOUR BEFORE ANY COMPUTE, BECAUSE R821 PAID TWO RUNS FOR SKIPPING THIS
  D1  Resampling does NOT move the point estimate, only the CI. So the 6 cells carry only 3
      DISTINCT point estimates. Any verdict change between two cells sharing a weighting is a
      change in PRECISION, never in the quantity. E1 must report both and say which moved.
  D2  Under any weighting w, ④'s margin is mean_w(arm − floor): both sides are linear in the same
      per-judgement values, so the margin is a REWEIGHTING of the per-prompt differences. Its sign
      can flip only if the per-prompt margin correlates with the weight. NOT forced -> measurable.
  D3  ⭐ CLAUSE ③ READS THE ARM'S SOURCE, NOT ITS SCORE. It therefore CANNOT move across estimand
      cells. If it moves, the instrument is broken, not the clause. This is a free falsifier on the
      grid itself and is checked before E1 is read.
  D4  This round settles what the evidence supports about the definition AS WRITTEN. It does not
      choose what the aggregation SHOULD be; if the verdict moves, the deliverable must NAME its
      aggregation, which is a repair to the text and not a new clause.

WORLDS

  B  THE VERDICT MOVES — "④ excludes 0 of 58" is a fact about the prompt-weighted default. The

  C  FORCED BY ALGEBRA — some cell is a reparameterisation of another. CHECKED FIRST via D1/D2.
