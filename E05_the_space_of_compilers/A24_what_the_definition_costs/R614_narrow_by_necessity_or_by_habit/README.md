# R614 · Narrow by habit — 9.9% of the era, and more clustered than chance

**Decision this makes safe:** whether the claim table's narrow window needs explaining. **It does.**

| | |
|---|---|
| era 431–606, rounds with artifacts | **171** |
| distinct rounds the claim table cites | **17** |
| **coverage of the era** | **17/171 = 0.0994** |
| coverage within its own span 519–581 | 17/63 = **0.2698** |
| **observed mean gap between cited rounds** | **3.8750** |
| null over 2,000 random 17-subsets | 5% **8.5000** · median **10.0000** · 95% **10.8125** |

**The cited set is far more clustered than chance.** Coverage is a **DERIVATION** — counts over a
complete enumeration; only the clustering is tested.

⭐ **So the concentration is a habit, not a shortage: 154 rounds of the same era exist and are not
cited.** *Why those seventeen* is now the live question about the definition's evidence base.

## ⛔ Check #213 over-fired, and the run exposed it
I objected that *"R519–R581, a 63-round window"* conflated **id positions** with **rounds**. The run
prints the answer: **that span holds 63 id positions AND 63 existing rounds** — the era is dense there,
so *"63-round window"* was **accurate**.

⚠ **My correction conflated *window size* with *cited count*.** The check was right that two units
were in play and **wrong about which number belonged to which.** *A units objection is itself a claim
about units, and it needs the same count the sentence it corrects needed.*

⚠ **And a drift, recorded rather than repeated silently:** R612's closing line asked to leave corpus
archaeology and return to the definition. R613 did exactly that — **and then its own closing line went
straight back.** This round ran the measurement because it is cheap and does bear on evidence
selection, but the pull is real and worth naming.

## Controls
| control | returned |
|---|---|
| **positive** — a contiguous block of 17 | mean gap **1.0000** vs null 5% **8.5000** — **clustering is detectable** |
| **positive @ g=0** — a random 17-subset | **10.0625**, inside [8.5000, 10.8125] — PASS, it can fail |
| **placebo** — the full era as its own cited set | coverage **exactly 1.0000** |
| **KILL** — clustering statistic needs ≥10 cited | **17 ≥ 10**, admissible |

⭐ **The g=0 arm is what makes the verdict readable**: a random subset lands squarely inside the null,
so the observed 3.8750 falling far below it is a property of the citation pattern and not of the
statistic.

**IMPOSSIBLE, named:** a citation may carry a **caveat** rather than a **number**, so coverage bounds
the evidence base **from above** and never characterises it.

## NEXT
Coverage and clustering are both properties of *which ids* were cited, and neither looks at *what
those rounds concluded*. **Take the 17 and the 154 and compare their `world` values** — the field
R611 showed became near-universal after the boundary. If the cited 17 skew toward one verdict class
while the uncited 154 spread across many, the selection tracks **outcome**, which is a different and
much sharper problem than tracking **position**.
