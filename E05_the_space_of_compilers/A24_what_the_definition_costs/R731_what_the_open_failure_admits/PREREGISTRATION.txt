ESTIMAND
   At the OBJECT level, do the three target-reading objects clause ③ admits sit with the object ③
   EXCLUDES, or with the label-blind topw objects, on clause ① and clause ② margins?
   This decides what the open failure costs: admitting known inflation, or admitting objects that
   behave like the ones the definition legitimately accepts.

IDENTIFICATION
   Identified from R728's persisted per-arm difference vectors, one representative tag per object
   from R730's partition. NOT identified: whether "sits with" has a principled threshold -- there is
   none, so the answer is given as a DISTANCE RATIO against the within-topw spread, which is the
   only floor this design has, and never as a bare classification.

SCOPE
   population : the 8 multi-tag objects plus the singleton target-reading objects, from R730's
                partition over today's 93 tags
   instrument : R294's contrast machinery on R728's cached difference vectors
   baseline   : the excluded oracle object and the four label-blind topw objects
   regime     : this tree_sha

WORLDS
   W-INFLATION  the three admitted objects sit with the excluded oracle. The open failure admits
                objects the definition already judged inadmissible, and ③ needs a PREDICATE rather
                than a longer list.
   W-MISDRAWN   they sit with the topw objects. Then the blocklist was drawn around the wrong
                property, and the defect is in the DEFINITION rather than in its implementation.
   prediction matrix
      all 3 closer to oracle        -> INFLATION 0.92  MISDRAWN 0.03
      all 3 closer to topw          -> INFLATION 0.02  MISDRAWN 0.92
      split                         -> both wrong; the object identity is doing work the rule name
                                       does not, and THAT is the finding

REGISTERED POINTS (failable; disclosed as non-blind)
   A  R522's six clause-② values reproduced from R728's cache          = 6    [0, 6]
   B  mean |clause-② gap| of the 3 admitted objects to the oracle object = 0.02 [0.00, 1.00]
   C  mean |clause-② gap| of the 3 admitted objects to the topw objects  = 0.04 [0.00, 1.00]
   D  of the 3, how many are closer to oracle than to topw on clause ②   = 3    [0, 3]
   DIRECTIONAL (separately failable): the same ordering holds on clause ① as on clause ②. Fails if
   any object's nearest group differs between the two clauses -- which would mean the two clauses
   disagree about what these objects are.

KILL (CONDITIONAL -- evaluated only if the POSITIVE and NEGATIVE controls both fire)
   if positive_fires and negative_collapses:
       D == 0            -> W-MISDRAWN: report that the blocklist is drawn around the wrong property
       D == 3            -> W-INFLATION
       otherwise         -> split; the finding is the disagreement and neither world is asserted
   else:
       verdict = UNVERIFIED   # never OVERTURNED, never CONFIRMED

POSITIVE CTRL   recompute R522's six clause-② effects from R728's cached vectors and require
                agreement to 4 decimals. threshold computed: floor 0 < t 6 <= ceiling 6. An
                instrument that cannot reproduce a prior round's published contrasts licenses
                nothing about new ones.
g=0             an object against ITSELF -> gap exactly 0. The control must not fire on nothing.
NEGATIVE CTRL   permute the object -> margin pairing and require the oracle/topw separation to
                collapse to its permutation null. excluded world: "any partition of these objects
                would show this separation", i.e. the grouping is doing no work.
SHAM            run the same separation on `n`, a per-object quantity that carries no clause
                information -- the ingredient ABSENT rather than inverted -- and require no
                separation.
PLACEBO         topw objects against each other -> gaps at the within-group floor, not above it.
NOISE FLOOR     the within-topw spread of clause-① and clause-② margins, measured across the four
                topw objects. Every distance is reported IN UNITS OF THAT SPREAD, because "sits
                with" has no absolute meaning.
MULTIPLICITY    2 clauses x (3 admitted + 1 excluded + 4 topw + 1 released core) objects x 2
                reference groups = every pairing reported.
SPECIFICATION   distance metric (absolute gap, gap in MDE units, gap in within-topw-spread units)
                x clause (①, ②) x representative tag choice (first tag, all tags averaged)
SEEDS           1000 permutations for the null, 3 seeds; two PYTHONHASHSEEDs byte-identical
ARTIFACT        results/r731_what_the_failure_admits.json with tree_sha
